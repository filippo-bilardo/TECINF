# Frogger v1.0

## Disegnare lo stage

Disegnare lo stage di Frogger in Scratch

L’obiettivo non è creare subito una grafica complessa, ma costruire:

* corsie chiare,
* aree riconoscibili,
* colori utili anche per le collisioni.

### Struttura classica dello stage

Lo stage può essere diviso in fasce orizzontali:

```text
+-----------------------------+
|        ARRIVO / TANE        |
+-----------------------------+
|           FIUME             |
|           FIUME             |
|           FIUME             |
+-----------------------------+
|       ZONA SICURA           |
+-----------------------------+
|          STRADA             |
|          STRADA             |
|          STRADA             |
+-----------------------------+
|        PARTENZA RANA        |
+-----------------------------+
```

---

### Metodo consigliato in Scratch

#### 1. Aprire l’editor sfondi

* Cliccare su **Stage**
* Scheda **Sfondi**
* Selezionare **Disegna**

---

#### 2. Disegnare le fasce principali

Conviene usare rettangoli colorati.

##### Colori suggeriti

| Zona               | Colore          |
| ------------------ | --------------- |
| Erba / zona sicura | Verde           |
| Strada             | Grigio scuro    |
| Fiume              | Blu             |
| Linee stradali     | Bianco o giallo |

---

#### 3. Disegnare la strada

##### Procedura

Usare:

* strumento rettangolo
* riempimento pieno

Disegnare:

* 3 corsie orizzontali

Esempio:

```text
========================
        STRADA
========================
```

Poi aggiungere:

* linee tratteggiate
* divisori

---

#### 4. Disegnare il fiume

Creare una fascia blu sopra la strada.

Suggerimento:

* usare un blu uniforme
* evitare sfumature all’inizio

Questo aiuta nelle collisioni:

```scratch
se tocca colore blu allora
```

---

#### 5. Creare le tane finali

In alto inserire:

* 3 o 5 aree di arrivo

Esempio:

```text
[ ]   [ ]   [ ]   [ ]
```

Possono essere:

* rettangoli neri
* cerchi
* piccole piazzole verdi

---

#### 6. Zona di partenza

In basso:

* fascia verde
* posizione iniziale della rana

## Dimensioni pratiche

Lo stage di Scratch è:

* X: da -240 a 240
* Y: da -180 a 180

Puoi dividere verticalmente in blocchi da:

* 40 o 50 pixel

Esempio:

| Area        | Coordinate Y |
| ----------- | ------------ |
| Arrivo      | 140 → 180    |
| Fiume       | 40 → 140     |
| Zona sicura | 0 → 40       |
| Strada      | -120 → 0     |
| Partenza    | -180 → -120  |

## Approccio didattico consigliato

### Prima versione

Fai creare:

* solo rettangoli colorati
* nessun dettaglio grafico

### Seconda versione (prossime esercitazioni)

Aggiungere:

* corsie
* bordi
* decorazioni
* texture

### Terza versione (prossime esercitazioni)

Inserire:

* animazioni
* acqua in movimento
* elementi grafici avanzati

# Evoluzione futura dello stage

* creare sfondi multipli
* cambiare livello
* introdurre temi diversi

  * città
  * spazio
  * neve
  * deserto

Questo permette anche di introdurre il concetto di:

* riuso del motore di gioco
* separazione tra logica e grafica.

# Suggerimento importante

Per le collisioni:

* usa colori molto distinti
* evita sfumature o immagini complesse all’inizio

Esempio:

* blu puro per acqua
* grigio puro per strada
* verde puro per aree sicure

Così i controlli saranno semplicissimi:

```scratch
se tocca colore [blu]
```

oppure

```scratch
se tocca colore [grigio]
```
